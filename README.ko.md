# Dolphin 배치 큐

[Comfy Registry](https://registry.comfy.org/ko/publishers/vzoo/nodes/dolphin-batch-queue)에 **aidispo (@vzoo)** 명의로 **0.1.0**이 게시되었습니다. Comfy CLI에서는 `comfy node install dolphin-batch-queue`로 설치할 수 있습니다.

ComfyUI를 재시작하고 브라우저를 새로고침하면 기본 사이드바에 시계 아이콘의 **배치 큐** 탭이 표시됩니다. 기존 설치에서 사이드바 UI 변경만 적용할 때는 브라우저 새로고침으로 충분합니다.

- 워크플로우를 열고 배치 이름과 개수를 입력해 **현재 워크플로우 예약**을 누릅니다. 워크플로우 6개를 각각 5개씩 예약하면 6개 배치, 30개 항목으로 관리합니다. 시드는 ComfyUI의 기존 fixed/increment/randomize 동작으로 확정됩니다.
- **재개**하면 전체 예약 순서대로 한 항목씩 실행합니다. 브라우저를 닫아도 서버가 계속 처리합니다.
- **일시정지**는 다음 예약부터 보류합니다. 현재 렌더는 마무리합니다. 일반 **Run**으로 급한 작업을 처리한 뒤 **재개**하세요.
- **워크플로우 수정**은 예약을 보류하고 해당 배치를 캔버스에 엽니다. 사이드바의 **배치에 저장**을 누르면 대기 항목을 모두 검증한 후 수정합니다. 이전 캔버스로 돌아오며, 자동 재개하지 않습니다.
- 수정된 입력만 배치에 반영하고, 항목별 시드와 변경하지 않은 개별 입력값은 보존합니다. 시드 노드를 삭제·교체하거나 시드 입력을 연결로 바꾸면 저장을 거절합니다. 완료·실행 중 항목은 수정하지 않습니다.
- **기존 큐 가져오기**는 현재 기본 큐의 대기 항목을 이동합니다. 실행 중 작업은 그대로 둡니다. 워크플로우 ID와 시드를 제외한 실행 설정이 같은 항목을 묶으므로, 원래 배치 경계가 없는 큐는 수동 예약과 다르게 묶일 수 있습니다. 인증 정보가 있는 작업이나 편집용 그래프가 없는 API 작업은 가져오지 않습니다.
- 실패 시 예약을 보류합니다. **항목 · 시드 보기**에서 출력 확인 후 재시도할 수 있습니다. 실패 항목도 수정하려면 먼저 재시도로 대기 상태로 복원하세요.

예약은 이 확장 폴더의 `.dolphin_queue/batches.json`에 저장합니다. 서버 재시작 후에는 보류 상태로 복원됩니다. 재시작 당시 실행 중이던 항목은 **확인 필요**로 표시하고 자동 재실행하지 않습니다.

로컬 단일 사용자 ComfyUI용입니다. 큐 상태는 서버 전체에서 공유합니다. Partner/API 노드의 Comfy 인증 토큰을 보관·갱신하지 않으므로 그런 작업은 기본 큐를 사용하세요. 워크플로우 입력 자체는 일반 워크플로우 저장과 동일하게 디스크에 보관됩니다.

검증: `python -m unittest discover -s tests -p test_dolphin_queue.py -v`. GPU 없는 UI 점검은 `python tests/queue_browser_harness.py` 실행 후 `http://127.0.0.1:8199`에서 할 수 있습니다.
